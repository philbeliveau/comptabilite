The extension follows the exact same pattern as TaxesQCExtension (taxes_qc/__init__.py):

1. **Class definition:**
   ```python
   class TableauBordExtension(FavaExtensionBase):
       report_title = "Tableau de bord"
   ```

2. **__init__ method:** Initialize private instance variables:
   - `self._kpis: dict = {}` (will hold 5 KPI values)
   - `self._revenus_mensuels: dict = {}` (chart data for line chart)
   - `self._depenses_categories: dict = {}` (chart data for doughnut)
   - `self._transactions_recentes: list[dict] = []` (last 10 transactions)

3. **after_load_file():** Call all four private compute methods:
   - `self._compute_kpis()`
   - `self._compute_revenus_mensuels()`
   - `self._compute_depenses_categories()`
   - `self._compute_transactions_recentes()`
   Wrap in try/except with logging to prevent a computation error from crashing the entire Fava load.

4. **_compute_kpis() method:**
   - Get current year: `annee = datetime.date.today().year`
   - Set date range: `debut = datetime.date(annee, 1, 1)`, `fin = datetime.date.today()`
   - Initialize `revenus = Decimal("0")` and `depenses = Decimal("0")`
   - Iterate `self.ledger.all_entries`:
     - Skip non-Transaction entries (use `isinstance(entry, data.Transaction)`)
     - Skip entries outside date range
     - For each posting: if account starts with "Revenus", subtract `posting.units.number` from revenus (negate because credits are negative). If starts with "Depenses", add to depenses.
     - CRITICAL: Check `posting.units is not None` before accessing `.number`
   - Compute pending count: `from compteqc.mcp.services import lister_pending; pending = lister_pending(self.ledger.all_entries)`
   - Compute tax owing (GST/QST net remittance):
     - `from compteqc.mcp.services import calculer_soldes`
     - `soldes = calculer_soldes(self.ledger.all_entries)`
     - `tps_percue = abs(soldes.get("Passifs:TPS-Percue", Decimal("0")))`
     - `tvq_percue = abs(soldes.get("Passifs:TVQ-Percue", Decimal("0")))`
     - `tps_payee = soldes.get("Actifs:TPS-Payee", Decimal("0"))`
     - `tvq_payee = soldes.get("Actifs:TVQ-Payee", Decimal("0"))`
     - `taxes_dues = (tps_percue + tvq_percue) - (tps_payee + tvq_payee)`
   - Store: `self._kpis = {"revenus_ytd": revenus, "depenses_ytd": depenses, "resultat_net": revenus - depenses, "taxes_dues": taxes_dues, "pending_count": len(pending)}`

5. **Public accessor kpis():** Return `self._kpis`

Imports needed:
- `from __future__ import annotations`
- `import datetime, json, logging`
- `from decimal import Decimal`
- `from fava.core import FavaLedger`
- `from fava.ext import FavaExtensionBase`
- `from beancount.core import data`

Use `logger = logging.getLogger(__name__)` at module level.

   - Initialize `categories: dict[str, Decimal] = {}`
   - Iterate entries in current year, for each posting starting with "Depenses:", extract second-level category: `parts = posting.account.split(":")`, `cat = parts[1] if len(parts) >= 2 else "Autres"`

4. **Public accessor methods:**
