  <action>
Create directory `src/compteqc/fava_ext/tableau_bord/templates/` and the template file. Follow the exact same Jinja2 pattern as TaxesQCExtension.html.

CRITICAL: Template file MUST be named `TableauBordExtension.html` to match the class name (Fava discovers templates by class name).

Structure the template with these sections:

1. **Page header:**
   ```html
   {% set page_title = "Tableau de bord" %}
   {% block content %}
   {% set kpis = extension.kpis() %}
   ```

2. **KPI row** (5 cards) using existing `.cqc-kpi-row` and `.cqc-kpi` classes:
   Each KPI card follows this pattern:
   ```html
   <div class="cqc-kpi">
     <div class="cqc-kpi-label">Revenus YTD</div>
     <div class="cqc-kpi-value" data-value="{{ kpis.revenus_ytd }}" data-decimals="2" data-suffix=" $">
       {{ "{:,.2f}".format(kpis.revenus_ytd) }} $
     </div>
   </div>
   ```

   The 5 KPIs in order:
   - **Revenus YTD**: `kpis.revenus_ytd`, decimals=2, suffix=" $"
   - **Depenses YTD**: `kpis.depenses_ytd`, decimals=2, suffix=" $"
   - **Resultat net**: `kpis.resultat_net`, decimals=2, suffix=" $", add class `cqc-success` if positive, `cqc-error` if negative
   - **Taxes dues**: `kpis.taxes_dues`, decimals=2, suffix=" $", label "Taxes dues (TPS/TVQ)"
   - **Approbations**: `kpis.pending_count`, decimals=0, no suffix, label "En attente"

   The server-rendered text inside the `div` serves as no-JS fallback and is overwritten by animateKPIs(). Always include the formatted value as text content.

3. **Charts row** -- Two chart containers side by side using a CSS grid wrapper:
   ```html
   <div class="cqc-dashboard-charts">
     <div class="cqc-card">
       <h3>Revenus mensuels {{ annee }}</h3>
       <div class="cqc-chart-container"
            id="chart-revenus-mensuels"
            data-chart='{{ extension.revenus_mensuels_json() }}'
            data-chart-type="line">
         <canvas></canvas>
       </div>
     </div>
     <div class="cqc-card">
       <h3>Depenses par categorie</h3>
       <div class="cqc-chart-container"
            id="chart-depenses-categories"
            data-chart='{{ extension.depenses_categories_json() }}'
            data-chart-type="doughnut">
         <canvas></canvas>
       </div>
     </div>
   </div>
   ```

   Where `annee` is obtained via `{% set annee = extension.kpis().get('annee', '') %}` or hardcode to current year display. Actually, use a Jinja2 `now()` or pass it from the extension. Since we can add a simple `annee()` method or just use the current year in the label text. Simplest: just write the year in the heading text as `{{ extension.annee() }}` -- add an `annee()` method to the extension that returns `datetime.date.today().year` (it is trivial, add to Plan 07-01 summary context, or simply use the KPI method).

   IMPORTANT: Use single-quote wrapping for the `data-chart` attribute value. Jinja2's `|tojson` filter or `json.dumps()` output uses double quotes internally, so wrapping the attribute in single quotes avoids escaping issues. The extension's `revenus_mensuels_json()` and `depenses_categories_json()` already return JSON strings.

4. **Recent transactions table:**
   ```html
   <div class="cqc-card">
     <h3>Transactions recentes</h3>
     <table class="cqc-table">
       <thead>
         <tr>
           <th>Date</th>
           <th>Description</th>
           <th class="montant">Montant</th>
           <th>Statut</th>
         </tr>
       </thead>
       <tbody>
         {% for txn in extension.transactions_recentes() %}
         <tr>
           <td>{{ txn.date }}</td>
           <td>{{ txn.payee }}{% if txn.narration %} &mdash; {{ txn.narration }}{% endif %}</td>
           <td class="montant">{{ "{:,.2f}".format(txn.montant) }} $</td>
           <td>
             {% if txn.statut == "pending" %}
               <span class="cqc-badge cqc-badge-warning">En attente</span>
             {% elif txn.statut == "attention" %}
               <span class="cqc-badge cqc-badge-danger">Attention</span>
             {% else %}
               <span class="cqc-badge cqc-badge-ok">OK</span>
             {% endif %}
           </td>
         </tr>
         {% endfor %}
         {% if not extension.transactions_recentes() %}
         <tr>
           <td colspan="4" class="cqc-empty-state">Aucune transaction trouvee.</td>
         </tr>
         {% endif %}
       </tbody>
     </table>
   </div>
   ```

5. **Close the block:**
   ```html
   {% endblock %}
   ```

6. **Dashboard grid CSS** -- Add a `<style>` block at the top of the template (inside the content block) for dashboard-specific layout that does not belong in the global theme:
   ```html
   <style>
     .cqc-dashboard-charts {
       display: grid;
       grid-template-columns: 1fr 1fr;
       gap: 24px;
       margin: 24px 0;
     }
     @media (max-width: 900px) {
       .cqc-dashboard-charts {
         grid-template-columns: 1fr;
       }
     }
   </style>
   ```

   This keeps the 2-column chart layout scoped to the dashboard. If other pages need similar layouts later, it can be promoted to the theme.
