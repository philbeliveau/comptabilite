  <name>Task 1: Chart.js CDN loader, chart registry, and renderCharts() engine</name>
  <files>src/compteqc/fava_ext/theme_qc/ThemeQCExtension.js</files>
  <action>
Add the following functions to ThemeQCExtension.js (above the export default block):

1. **Chart.js lazy CDN loader** -- `loadChartJs()`:
   - Returns a Promise that resolves when Chart.js is available on `window.Chart`
   - If `window.Chart` already exists, resolve immediately
   - If a load is in progress (Promise cached in module-scope `chartJsPromise`), return the existing Promise
   - Otherwise, create a `<script>` element with `src="https://cdn.jsdelivr.net/npm/chart.js@4.4.8/dist/chart.umd.min.js"`, append to `document.head`, resolve on `onload`, reject on `onerror`
   - Module-scope variables: `let chartJsPromise = null;`

2. **Chart registry** -- module-scope `const chartRegistry = new Map();`:
   - Keys: string identifier (canvas ID or container ID)
   - Values: Chart.js instance
   - Helper function `destroyAllCharts()`: iterate registry, call `.destroy()` on each Chart instance, then `registry.clear()`

3. **renderCharts()** -- async function:
   - Call `destroyAllCharts()` first (clean up previous navigation's charts)
   - Query `document.querySelectorAll('.cqc-chart-container[data-chart]')`
   - If no containers found, return early (most pages have no charts)
   - `await loadChartJs()` -- only loads Chart.js when a page actually has charts
   - For each container:
     - Get `canvas` child element; skip if not found
     - Parse `JSON.parse(container.dataset.chart)` for chart data
     - Read `container.dataset.chartType || 'bar'` for chart type
     - Read optional `container.dataset.chartOptions` for per-chart option overrides (JSON)
     - Create `new Chart(canvas, { type, data, options: { responsive: true, maintainAspectRatio: false, plugins: { legend: { labels: { font: { family: "'Inter', sans-serif" } } } }, ...getChartThemeOptions(type), ...customOptions } })`
     - Store in `chartRegistry.set(container.id || canvas.id || 'chart-' + index, chartInstance)`
   - Use try/catch around JSON.parse and Chart creation -- log errors to console, do not crash

4. **getChartThemeOptions(type)** -- helper returning Quebec-palette defaults:
   - For 'line': `{ elements: { line: { tension: 0.3, borderColor: '#003DA5', borderWidth: 2 }, point: { radius: 0, hoverRadius: 6, backgroundColor: '#003DA5' } }, scales: { y: { ticks: { callback: v => v.toLocaleString('fr-CA') + ' $' }, grid: { color: 'rgba(0,61,165,0.08)' } }, x: { grid: { display: false } } } }`
   - For 'doughnut': `{ plugins: { legend: { position: 'right', labels: { padding: 16, usePointStyle: true } } } }` with Quebec blue palette colors array
   - For 'bar': similar to line but with `backgroundColor: 'rgba(0,61,165,0.7)'`
   - Default: empty object

5. **Update `onPageLoad()`**: Add `renderCharts();` call after `attachTooltips()`. This is an async call but does not need await -- fire and forget is fine since chart rendering is non-blocking.

6. **Update `init()`**: Add `loadChartJs();` call (non-blocking pre-load so Chart.js is cached by the time user navigates to a chart page). Do NOT await it -- init should remain synchronous.

Do NOT add Chart.js CSS to THEME_CSS yet -- that is Plan 06-02's scope (chart container sizing CSS).

  <name>Task 2: KPI count-up animation, page entry animation, and prefers-reduced-motion guards</name>
  <files>src/compteqc/fava_ext/theme_qc/ThemeQCExtension.js</files>
  <action>
Add the following to ThemeQCExtension.js:

1. **animateKPIs()** function:
   - Query `document.querySelectorAll('.cqc-kpi-value[data-value]')`
   - If none found, return early
   - Check `prefersReducedMotion()` -- if true, leave the server-rendered text as-is (do not animate)
   - For each element:
     - Read `parseFloat(el.dataset.value)` as target
     - Read `el.dataset.prefix || ''` (e.g., '' or '$ ')
     - Read `el.dataset.suffix || ' $'` (default suffix is ' $' for French Canadian convention)
     - Read `parseInt(el.dataset.decimals || '0', 10)` for decimal places
     - Duration: 800ms
     - Use `requestAnimationFrame` loop with ease-out cubic: `eased = 1 - Math.pow(1 - progress, 3)`
     - Format current value with `new Intl.NumberFormat('fr-CA', { minimumFractionDigits: decimals, maximumFractionDigits: decimals })` then prepend prefix and append suffix
     - Set `el.textContent` on each frame
     - On completion (progress >= 1), set final exact value to avoid floating point drift

2. **prefersReducedMotion()** helper:
   - Return `window.matchMedia('(prefers-reduced-motion: reduce)').matches`
   - Cache the MediaQueryList in module scope for reuse

3. **animatePageEntry()** function:
   - Check `prefersReducedMotion()` -- if true, return immediately (no animation)
   - Get `document.querySelector('article')`; if not found, return
   - Remove class `cqc-page-entering`, force reflow via `void article.offsetWidth`, add class `cqc-page-entering`
   - The CSS keyframe `cqc-page-enter` will handle the visual effect

4. **Add CSS keyframes and reduced-motion guard to THEME_CSS constant**:
   - Add at the END of the THEME_CSS string (before the closing backtick):
   ```css
   /* === Page entry animation === */
   @keyframes cqc-page-enter {
     from { opacity: 0; transform: translateY(6px); }
     to { opacity: 1; transform: translateY(0); }
   }
   .cqc-page-entering {
     animation: cqc-page-enter 200ms ease-out;
   }

   /* === KPI card staggered entrance === */
   @keyframes cqc-fadeSlideUp {
     from { opacity: 0; transform: translateY(12px); }
     to { opacity: 1; transform: translateY(0); }
   }

   /* === Reduced motion safety net === */
   @media (prefers-reduced-motion: reduce) {
     *, *::before, *::after {
       animation-duration: 0.01ms !important;
       animation-iteration-count: 1 !important;
       transition-duration: 0.01ms !important;
       scroll-behavior: auto !important;
     }
     .cqc-page-entering {
       animation: none;
     }
   }
   ```
   Note: the `!important` on reduced-motion is one of the legitimate uses -- it is an accessibility override that MUST win over any other animation declaration.

5. **Update `onPageLoad()`**: Add `animatePageEntry();` at the BEGINNING (before other DOM manipulations so the fade-in covers the content setup). Add `animateKPIs();` after `renderCharts()`.

6. **Add chart container CSS to THEME_CSS** (needed for Phase 7):
   ```css
   /* === Chart containers === */
   .cqc-chart-container {
     position: relative;
     width: 100%;
     height: 300px;
     padding: 16px;
   }
   .cqc-chart-container canvas {
     width: 100% !important;
     height: 100% !important;
   }
   ```
   Note: the canvas `!important` is needed because Chart.js sets inline width/height that must be overridden for responsive behavior.
