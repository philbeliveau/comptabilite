  <action>
Add ARIA attributes to all extension templates and ThemeQCExtension.js. Work through each file systematically:

**1. TableauBordExtension.html (Dashboard):**
- Add `aria-label="Graphique des revenus mensuels"` and `role="img"` to the revenue line chart `<canvas>` element
- Add `aria-label="Graphique des depenses par categorie"` and `role="img"` to the expense doughnut chart `<canvas>` element
- KPI values already have server-rendered fallback text inside `data-value` elements (Phase 7 decision), so no change needed there

**2. ApprobationExtension.html (Approval queue):**
- Add `role="meter"` `aria-valuenow="{{ (txn.confiance * 100)|round|int }}"` `aria-valuemin="0"` `aria-valuemax="100"` `aria-label="Confiance: {{ (txn.confiance * 100)|round|int }}%"` to each confidence bar div (the `.cqc-confidence` elements)
- Add `aria-label="Approuver"` to approve buttons and `aria-label="Rejeter"` to reject buttons if they only show icons
- Add `aria-describedby` linking the keyboard shortcut hint text to the approval table, so screen readers announce that shortcuts exist
- Ensure any reject textarea/input has an associated `<label>` element (use `for=` attribute matching the input `id`)

**3. RecusExtension.html (Receipts/Upload):**
- Add `role="button"` and `aria-label="Zone de depot: glissez un fichier ou cliquez pour telecharger"` to the dropzone `<div>`
- Add `tabindex="0"` to the dropzone so it is keyboard-focusable
- Ensure the file `<input type="file">` has an associated `<label>`

**4. PaieQCExtension.html, TaxesQCExtension.html, DpaQCExtension.html, PretActionnaireExtension.html:**
- Add `aria-label` attributes to any tooltip-trigger elements (the info icons/buttons that show tooltips on hover)
- Ensure all `<table>` elements have a `<caption>` element with a brief description (e.g., `<caption class="cqc-sr-only">Detail de la paie</caption>`)
- If any section has summary numbers, ensure they are in semantic `<th>` or `<tfoot>` elements

**5. ThemeQCExtension.js -- sidebar badge aria-live:**
- In the `updateSidebarBadge()` function, after creating/updating the badge element, set:
  ```javascript
  badge.setAttribute('aria-live', 'polite');
  badge.setAttribute('aria-label', data.count + ' transactions en attente');
  ```
- Add a `.cqc-sr-only` CSS class to THEME_CSS for screen-reader-only content (visually hidden but accessible):
  ```css
  .cqc-sr-only {
    position: absolute;
    width: 1px;
    height: 1px;
    padding: 0;
    margin: -1px;
    overflow: hidden;
    clip: rect(0, 0, 0, 0);
    white-space: nowrap;
    border: 0;
  }
  ```

**6. Keyboard shortcut scoping (from 10-RESEARCH.md Open Question 1):**
- In the approval table, add `aria-roledescription="Tableau interactif avec raccourcis clavier"` to the table element
- Add an `aria-describedby` region near the table that describes available shortcuts (j/k/Space/a)
- Do NOT change the current keyboard shortcut behavior (research recommends keeping it as-is unless screen reader usage is confirmed)
