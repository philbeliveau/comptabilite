```python
"""Calcul du vieillissement (aging) des comptes clients et fournisseurs."""

from __future__ import annotations
import datetime
from dataclasses import dataclass, field
from decimal import Decimal
from typing import TYPE_CHECKING

if TYPE_CHECKING:
    from compteqc.factures.modeles import Facture
    from compteqc.fournisseurs.modeles import FactureFournisseur

BUCKETS = ["0-30", "31-60", "61-90", "91+"]

@dataclass
class LigneVieillissement:
    """One entry in an aging report."""
    identifiant: str       # Invoice/bill number
    nom: str               # Client or vendor name
    date_document: datetime.date
    date_echeance: datetime.date
    total: Decimal
    paye: Decimal
    solde: Decimal
    jours_echus: int       # Days past due (negative = not yet due)
    tranche: str           # Bucket: "0-30", "31-60", "61-90", "91+"

@dataclass
class ResumeVieillissement:
    """Summary of aging report for one side (AR or AP)."""
    lignes: list[LigneVieillissement] = field(default_factory=list)
    totaux_par_tranche: dict[str, Decimal] = field(default_factory=dict)
    nombre_par_tranche: dict[str, int] = field(default_factory=dict)
    total_impaye: Decimal = Decimal("0")
    nombre_total: int = 0

@dataclass
class PositionAPAR:
    """Combined AP/AR position."""
    ar: ResumeVieillissement
    ap: ResumeVieillissement
    position_nette: Decimal          # AR total - AP total (positive = net receivable)
    encaissements_30j: Decimal       # AR amounts in 0-30 bucket
    paiements_30j: Decimal           # AP amounts in 0-30 bucket
    flux_net_30j: Decimal            # encaissements - paiements
```

Functions:

1. `calculer_age_jours(date_echeance: date, date_reference: date | None = None) -> int` -- returns (ref - echeance).days
2. `classifier_age(jours: int) -> str` -- maps days to bucket string. Use 0-30 for jours <= 30, 31-60 for 31-60, 61-90 for 61-90, 91+ for 91+
3. `calculer_vieillissement_ar(factures: list[Facture], date_reference: date | None = None) -> ResumeVieillissement`:
   - Filter to unpaid (solde > 0) invoices
   - For each: compute jours_echus, classify bucket, build LigneVieillissement
   - Aggregate totaux_par_tranche and nombre_par_tranche (initialize all 4 buckets to 0)
   - Sum total_impaye
4. `calculer_vieillissement_ap(factures: list[FactureFournisseur], date_reference: date | None = None) -> ResumeVieillissement`:
   - Same logic but for AP bills (use fournisseur for nom, numero_interne for identifiant, date_facture for date_document)
5. `rapport_position_apar(ar: ResumeVieillissement, ap: ResumeVieillissement) -> PositionAPAR`:
   - position_nette = ar.total_impaye - ap.total_impaye
   - encaissements_30j = ar.totaux_par_tranche["0-30"]
   - paiements_30j = ap.totaux_par_tranche["0-30"]
   - flux_net_30j = encaissements_30j - paiements_30j

NOTE: The functions accept lists of model objects, NOT registries. The CLI layer (Plan 02) will be responsible for loading from registries and passing to these functions. This keeps the aging module pure and testable.
