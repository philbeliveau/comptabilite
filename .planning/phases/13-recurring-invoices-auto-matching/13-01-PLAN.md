<objective>
Implement recurring invoice templates and automatic generation for the AR system.

Purpose: A solo IT consultant with monthly retainer clients should not manually create the same invoice every month. Recurring templates automate this pattern, reducing manual work and ensuring invoices are never forgotten.

Output: `ModeleFactureRecurrente` model, YAML-persisted template registry, generation logic that creates `Facture` instances from due templates, and CLI commands for managing templates and triggering generation.
</objective>

```python
"""Factures recurrentes -- modeles et generation automatique."""

from __future__ import annotations
import datetime
from decimal import Decimal
from pathlib import Path
from typing import Optional
from dateutil.relativedelta import relativedelta
from pydantic import BaseModel
import yaml

from compteqc.factures.modeles import Facture, InvoiceStatus, LigneFacture
from compteqc.factures.registre import RegistreFactures


class ModeleFactureRecurrente(BaseModel):
    """Template for generating recurring invoices."""
    identifiant: str              # e.g. "REC-ACME-MENSUEL"
    nom_client: str
    adresse_client: str = ""
    lignes: list[LigneFacture]
    frequence: str = "mensuel"    # mensuel, bimensuel, trimestriel, annuel
    jour_generation: int = 1      # Day of month to generate
    prochaine_generation: datetime.date
    actif: bool = True
    notes: str = ""
    echeance_jours: int = 30      # Payment terms in days
```

Implement `RegistreRecurrents` following the exact same pattern as `RegistreFactures`:
- `__init__(chemin)` with default path `ledger/factures/modeles-recurrents.yaml`
- `_charger()`, `_sauvegarder()` -- YAML persistence
- `ajouter(modele)` -- add template, raise ValueError if identifiant exists
- `obtenir(identifiant)` -- get by ID
- `lister(actif_seulement=True)` -- list templates, optionally filter active only
- `mettre_a_jour(modele)` -- replace template by identifiant

Implement `avancer_date(frequence: str, date_courante: datetime.date) -> datetime.date`:
- "mensuel" -> +1 month (using `relativedelta(months=1)`)
- "bimensuel" -> +2 weeks (using `datetime.timedelta(weeks=2)`)
- "trimestriel" -> +3 months
- "annuel" -> +12 months
- Raise ValueError for unknown frequency

Implement `generer_factures_recurrentes(registre_recurrents, registre_factures, date_reference=None) -> list[Facture]`:
- For each active template where `prochaine_generation <= date_reference`:
  - Create a `Facture` with `prochain_numero()` from `registre_factures`
  - Set `date` = `prochaine_generation`, `date_echeance` = date + echeance_jours
  - Copy `lignes`, `nom_client`, `adresse_client`, `notes` from template
  - Set `statut` = `InvoiceStatus.DRAFT`
  - Add facture to `registre_factures`
  - Advance template's `prochaine_generation` using `avancer_date()`
  - Save updated template to `registre_recurrents`
- Return list of generated factures

**IMPORTANT:** Use `python-dateutil` for `relativedelta`. Check if it's already a dependency; if not, add it to `pyproject.toml` under `[project.dependencies]`.

**REFACTOR:** Ensure all Decimal fields use the same `_coerce_decimal` pattern as other models.
