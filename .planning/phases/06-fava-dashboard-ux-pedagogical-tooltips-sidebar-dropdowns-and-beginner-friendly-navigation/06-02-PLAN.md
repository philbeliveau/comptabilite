1. **`TOOLTIPS` dictionary** — a JS object keyed by the exact `textContent.trim()` of table headers, KPI labels, and metric names. Each value has `text` (French explanation) and `source` (Python function path). Cover ALL reports:

   **Paie Quebec (PaieQCExtension):**
   - "Salaire brut": cumul annuel du salaire avant toute retenue. Source: paie.moteur.calculer_paie().salaire_brut
   - "Salaire brut YTD": same as above but year-to-date. Source: paie.ytd.calculer_cumuls()
   - "Retenues employe" / "Total retenues": somme de toutes les deductions prelevees sur le salaire (impots, RRQ, RQAP, AE). Source: paie.moteur.calculer_paie()
   - "Cotisations employeur" / "Total employeur": montant additionnel paye par la societe (part employeur RRQ, RQAP, AE, FSS, CNESST, normes). Source: paie.moteur.calculer_paie()
   - "Salaire net": montant deposer dans le compte bancaire apres toutes les retenues. Source: paie.moteur.calculer_paie().salaire_net
   - "RRQ (base)": Regime de rentes du Quebec, part de base. Cotisation retraite obligatoire. Source: paie.cotisations.calculer_rrq_base()
   - "RRQ (supp1)": premiere cotisation supplementaire RRQ depuis 2024. Source: paie.cotisations.calculer_rrq_supp1()
   - "RRQ (supp2)": deuxieme cotisation supplementaire RRQ depuis 2024 (sur les gains entre le 1er et 2e plafond). Source: paie.cotisations.calculer_rrq_supp2()
   - "RQAP": Regime quebecois d'assurance parentale. Cotisation pour les conges parentaux. Source: paie.cotisations.calculer_rqap()
   - "AE" / "Assurance-emploi": cotisation federale d'assurance-emploi (taux reduit au Quebec). Source: paie.cotisations.calculer_ae()
   - "FSS": Fonds des services de sante. Taxe employeur sur la masse salariale totale. Source: paie.cotisations.calculer_fss()
   - "CNESST": Commission des normes, de l'equite, de la sante et de la securite du travail. Assurance accidents de travail. Source: paie.cotisations.calculer_cnesst()
   - "Normes du travail": contribution obligatoire a la Commission des normes. Source: paie.cotisations.calculer_normes_travail()
   - "Impot federal": retenue d'impot federal calculee selon les tables T4127 avec l'abattement Quebec de 16.5%. Source: paie.impots.calculer_impot_federal()
   - "Impot Quebec" / "Impot provincial": retenue d'impot Quebec calculee selon le guide TP-1015.F-V. Source: paie.impots.calculer_impot_quebec()
   - "Cout total": salaire brut + toutes les cotisations employeur. Le vrai cout d'un employe pour la societe. Source: paie.moteur.calculer_paie()
   - "Maximum atteint": ce symbole indique que la cotisation annuelle maximale est atteinte. Les prelevements s'arretent pour le reste de l'annee.
   - "Periode": le numero de la paie dans l'annee (ex: 12/26 = 12e paie sur 26 bi-hebdomadaires).

   **TPS/TVQ (TaxesQCExtension):**
   - "TPS percue": Taxe sur les produits et services (5%) facturee a vos clients. Vous la collectez pour le gouvernement federal. Source: taxes.sommaire.calculer_sommaire_tps_tvq()
   - "TVQ percue": Taxe de vente du Quebec (9.975%) facturee a vos clients. Vous la collectez pour Revenu Quebec. Source: taxes.sommaire.calculer_sommaire_tps_tvq()
   - "TPS payee" / "CTI": Credit de taxe sur les intrants. TPS payee sur vos achats d'affaires que vous pouvez recuperer. Source: taxes.sommaire.calculer_sommaire_tps_tvq()
   - "TVQ payee" / "RTI": Remboursement de la taxe sur les intrants. TVQ payee sur vos achats d'affaires que vous pouvez recuperer. Source: taxes.sommaire.calculer_sommaire_tps_tvq()
   - "Net a remettre" / "Remise nette": percue - payee = ce que vous devez envoyer au gouvernement. Si negatif, vous avez droit a un remboursement. Source: taxes.sommaire.calculer_sommaire_tps_tvq()
   - "Periode": la periode de declaration (annuelle ou trimestrielle) pour laquelle les taxes sont calculees.

   **DPA/CCA (DpaQCExtension):**
   - "FNACC ouverture" / "UCC ouverture": Fraction non amortie du cout en capital au debut de l'annee. La valeur comptable restante de vos actifs. Source: dpa.calcul.calculer_dpa()
   - "Acquisitions": nouveaux actifs achetes pendant l'annee, classes par categorie. Source: dpa.registre.RegistreActifs
   - "Dispositions": actifs vendus ou mis au rebut pendant l'annee. Source: dpa.registre.RegistreActifs
   - "DPA de l'annee" / "CCA de l'annee": deduction pour amortissement que vous pouvez reclamer cette annee. Reduit votre revenu imposable. Source: dpa.calcul.calculer_dpa()
   - "FNACC fermeture" / "UCC fermeture": valeur comptable restante a la fin de l'annee. FNACC ouverture + acquisitions - dispositions - DPA. Source: dpa.calcul.calculer_dpa()
   - "Taux": le pourcentage de deduction annuel fixe par le gouvernement pour cette classe d'actifs.
   - "Classe 8": mobilier, appareils, equipement de bureau. Taux 20%.
   - "Classe 10": vehicules automobiles. Taux 30%.
   - "Classe 12": logiciels, petit outillage. Taux 100%.
   - "Classe 50": materiel informatique (ordinateurs, ecrans, serveurs) achete apres 2023. Taux 55%.
   - "Classe 54": vehicules zero emission. Taux variable.
   - "Regle du demi-taux" / "Half-year rule": la premiere annee, seulement 50% de la DPA normale est permise. Source: dpa.calcul.calculer_dpa()

   **Pret actionnaire (PretActionnaireExtension):**
   - "Solde net": balance nette du compte de pret actionnaire. Positif = la societe vous doit de l'argent. Negatif = vous devez de l'argent a la societe. Source: pret_actionnaire.suivi.obtenir_etat_pret()
   - "Direction": indique qui doit de l'argent a qui (societe -> actionnaire ou actionnaire -> societe).
   - "Avances ouvertes": montants pretes a l'actionnaire qui n'ont pas encore ete rembourses.
   - "Date limite s.15(2)": si un pret n'est pas rembourse avant cette date (1 an apres la fin de l'exercice fiscal), le montant est ajoute a votre revenu personnel et impose. Source: pret_actionnaire.suivi.verifier_delais_s152()
   - "Compte a rebours": nombre de jours restants avant la date limite s.15(2). Rouge = urgent.
   - "Alerte critique": moins de 30 jours avant inclusion s.15(2). Action immediate requise.
   - "Alerte urgente": moins de 90 jours (3 mois) avant inclusion s.15(2).

   **File d'approbation (ApprobationExtension):**
   - "Confiance": probabilite (0-100%) que la categorie suggeree par l'IA est correcte. Plus c'est haut, plus le systeme est sur de son choix. Source: categorisation.pipeline.PipelineCategorisation
   - "Source IA": quel moteur a categorise cette transaction (regle = systeme de regles, ml = apprentissage automatique, llm = Claude). Source: categorisation.pipeline
   - "Compte propose": le compte comptable suggere par l'IA pour cette transaction.
   - "Gros montant": transactions de plus de 2 000 $ qui necessitent une confirmation explicite avant approbation.

   **Native Fava tables** (broader matches):
   - "Account" / "Compte": le nom du compte comptable dans le plan comptable. Chaque transaction touche au moins 2 comptes.
   - "Balance": le solde du compte. Debit positif pour les actifs et depenses, credit positif pour les passifs, capitaux et revenus.
   - "Position": la valeur totale detenue dans ce compte, incluant la devise.
   - "Change": la variation du solde pendant la periode selectionnee.
   - "Narration": la description de la transaction telle qu'importee de la banque ou saisie manuellement.
   - "Date": la date a laquelle la transaction a ete enregistree dans le ledger.

2. **`attachTooltips()` function** that:
   - First removes ALL existing `data-tooltip` and `tabindex` attributes from previously tooltipped elements (query `[data-tooltip]` and remove attributes) for idempotent re-run
   - Queries ALL potential tooltip targets:
     - `.cqc-table th` (extension report table headers)
     - `.cqc-kpi-label` (KPI tile labels)
     - `.cqc-kpi-value` (KPI values -- match by nearest .cqc-kpi-label sibling textContent)
     - `article table th` (native Fava table headers)
     - `.cqc-section-title` (section titles that might match)
     - `article .tree-table td.account-cell` (Fava tree table account names -- if relevant)
   - For each element, does `const text = el.textContent.trim()` and looks up `TOOLTIPS[text]`
   - If found, sets `el.setAttribute("data-tooltip", tip.text + (tip.source ? "\n\nSource : " + tip.source : ""))` and `el.setAttribute("tabindex", "0")` for tablet focus accessibility
   - Special handling for `.cqc-kpi-value`: look up the tooltip using the SIBLING `.cqc-kpi-label` text instead (since the value itself is a number, not a label)

3. **Wire `attachTooltips()` into `onPageLoad()`** in the module export:
   ```javascript
   onPageLoad() {
     injectStyle();
     injectBrand();
     reorganizeSidebar();
     injectReportHeader();
     attachTooltips();
   },
   ```

Important implementation notes:
- The tooltip `content: attr(data-tooltip)` CSS does NOT support newlines. Replace `\n` with ` — ` or use a different separator for the source line, OR switch to a JS-created tooltip element approach. RECOMMENDED: keep CSS tooltips but format text as a single line with " | Source: ..." at the end.
- For `.cqc-kpi-value` elements, traverse to the parent `.cqc-kpi` and find `.cqc-kpi-label` to get the lookup key.
- Add fallback: if exact match fails, try case-insensitive or partial match (e.g., "Salaire brut" matches "SALAIRE BRUT" in uppercase th).
