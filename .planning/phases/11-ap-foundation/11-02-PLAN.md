**Function 1: `generer_ecriture_facture_fournisseur(facture: FactureFournisseur) -> str`**

This generates the bill recording entry. The logic is more complex than AR because:
- Each line item posts to its own expense account (not a single revenue account)
- ITC/ITR may be partial (taux_itc/taux_itr < 1.0), requiring the non-claimable portion to be added to the expense

Algorithm for each line:
1. Start with the pre-tax amount -> debit to `ligne.categorie_depense`
2. If `ligne.tps_applicable`:
   - Calculate full GST: `ligne.montant * TAUX_TPS`
   - Claimable ITC: `full_gst * ligne.taux_itc` -> debit to `Actifs:TPS-Payee`
   - Non-claimable: `full_gst - claimable_itc` -> debit to `ligne.categorie_depense`
3. Same logic for QST with `taux_itr` and `Actifs:TVQ-Payee`
4. Credit `Passifs:ComptesFournisseurs` for the bill total (negative amount)

The entry must balance: sum of all debits = bill total = credit to AP.

Implementation approach:
- Build a dict mapping account names to accumulated Decimal amounts (to consolidate multiple lines posting to the same expense account)
- Process each line, accumulating debits
- Add the AP credit at the end
- Format as Beancount syntax

Entry format:
```
YYYY-MM-DD * "Facture fournisseur FOUR-2026-001 - Vendor Name"
  Depenses:Category1  XXX.XX CAD
  Depenses:Category2  YYY.YY CAD
  Actifs:TPS-Payee     ZZ.ZZ CAD
  Actifs:TVQ-Payee     ZZ.ZZ CAD
  Passifs:ComptesFournisseurs  -TTTT.TT CAD
```

Use `collections.defaultdict(Decimal)` to accumulate postings by account. Round each individual amount to the cent. The AP credit must equal the negative of the sum of all debit postings (the entry must balance exactly).

To ensure balance: compute the AP credit as the negative sum of all debit postings. Do NOT independently compute it from bill.total -- compute it as the balancing amount.

**Function 2: `generer_ecriture_paiement_fournisseur(facture: FactureFournisseur, montant: Decimal | None = None, methode: str | None = None, date_paiement=None) -> str`**

This generates the payment entry. Simpler than bill recording:
- `montant`: amount being paid. If None, defaults to `facture.solde` (full remaining balance).
- `methode`: payment method string. If None, uses `facture.methode_paiement` or defaults to "cheque".
- `date_paiement`: payment date. If None, uses `facture.date_paiement` or today.

Determine the credit account from `COMPTE_PAIEMENT.get(methode, COMPTE_PAIEMENT_DEFAUT)`.

Entry format:
```
YYYY-MM-DD * "Paiement facture fournisseur FOUR-2026-001 - Vendor Name"
  Passifs:ComptesFournisseurs  MONTANT CAD
  Actifs:Banque:RBC:Cheques  -MONTANT CAD
```

Note the signs: AP debit is positive (reducing the liability), bank credit is negative.

For partial payments, the narration should include "partiel": `"Paiement partiel facture fournisseur..."` when `montant < facture.total`.

```python
def _parse_amounts(entry: str) -> list[Decimal]:
    """Extract all CAD amounts from a Beancount entry string."""
    import re
    amounts = []
    for line in entry.strip().split("\n"):
        match = re.search(r'(-?[\d,]+\.?\d*)\s+CAD', line)
        if match:
            amounts.append(Decimal(match.group(1).replace(",", "")))
    return amounts

def _assert_balanced(entry: str) -> None:
    """Assert that a Beancount entry balances (sum of all postings == 0)."""
    amounts = _parse_amounts(entry)
    total = sum(amounts)
    assert total == Decimal("0"), f"Entry does not balance: sum={total}\n{entry}"
```
