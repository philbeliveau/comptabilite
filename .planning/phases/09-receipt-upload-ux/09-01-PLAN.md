**RecusExtension.html changes:**

1. Remove the `<form>` wrapper entirely (no more form submit). Keep the dropzone div and hidden file input outside any form.

2. Remove ALL inline event handlers (`ondragover`, `ondragleave`, `ondrop`, `onchange`, `onclick`). These will be replaced by addEventListener in the script block.

3. Add a progress bar section below the dropzone (hidden by default):
```html
<div id="upload-progress" class="cqc-upload-progress" style="display: none;">
  <div class="cqc-upload-progress-bar" id="progress-bar">
    <span class="cqc-upload-progress-text" id="progress-text">0%</span>
  </div>
</div>
<div id="upload-status" class="cqc-upload-status" style="display: none;"></div>
```

4. Add a results container for match rendering:
```html
<div id="upload-result" style="display: none;"></div>
```

5. Add an inline `<script>` block (matching ApprobationExtension pattern) at the bottom of the template with:

   a. **Constants:** `UPLOAD_URL` from the Jinja template: `'{{ "/" ~ g.beancount_file_slug ~ "/extension/" ~ extension.name ~ "/upload" }}'`. Same pattern for `LINK_URL`.

   b. **Dropzone click handler:** clicks the hidden file input.

   c. **File input change handler:** when file selected, call `uploadFile(input.files[0])`.

   d. **`uploadFile(file)` function** using XMLHttpRequest:
      - Create FormData, append `'fichier'` key (must match server).
      - Show progress bar, hide any previous results.
      - `xhr.upload.onprogress`: update progress bar width and text with real percentage (`Math.round(e.loaded / e.total * 100)`).
      - When progress reaches 100%, show "Traitement en cours..." in the status div (server is processing/extracting).
      - `xhr.onload`: Parse JSON response. If status === "ok", call `renderResult(data)`. If error, show error message.
      - `xhr.onerror`: Show network error message.

   e. **`renderResult(data)` function:**
      - Show the upload-result div.
      - Render an extraction summary card if `data.extracted` is not null (fournisseur, date, total, confiance as percentage).
      - If `data.correspondances.length > 0`, render a match table with Date, Narration, Montant, Score columns, plus a "Lier" button per row. The Lier button submits a hidden form POST to `LINK_URL` with chemin_recu, entry_hash, date_txn, compte fields (same as current HTML builder). This form POST is still a regular form submit (redirects back to the recus page) -- that's the intended flow.
      - If no correspondances, show "Aucune correspondance trouvee."
      - Reset the file input and hide the progress bar.

   f. **`updateProgressBar(pct)` function:** sets width style and text content on progress bar elements.
