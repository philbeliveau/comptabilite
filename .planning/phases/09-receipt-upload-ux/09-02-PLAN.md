**RecusExtension.html script changes:**

1. **Replace basic drag handlers with counter pattern.** Plan 09-01 removed inline handlers and added addEventListener for basic drag events. Now enhance them:

   a. Add `let dragCounter = 0;` variable.
   b. `dragenter` handler: `e.preventDefault(); dragCounter++; dropzone.classList.add('dragover');`
   c. `dragleave` handler: `e.preventDefault(); dragCounter--; if (dragCounter === 0) dropzone.classList.remove('dragover');`
   d. `dragover` handler: `e.preventDefault();` (required to allow drop).
   e. `drop` handler: `e.preventDefault(); dragCounter = 0; dropzone.classList.remove('dragover'); const files = Array.from(e.dataTransfer.files); uploadFiles(files);`

2. **Multi-file support with sequential upload.** Add `async function uploadFiles(files)`:
   - Add a file queue status display above the progress bar showing "Fichier {i+1} sur {files.length}: {file.name}".
   - Loop through files sequentially: `for (let i = 0; i < files.length; i++)`.
   - For each file, update the queue status text, call the existing `uploadFile(file)` wrapped in a Promise (or convert it to return a Promise if not already done in 09-01).
   - After each file completes, render its preview (see Task 2 output: `renderPreview(file, data)`).
   - After ALL files complete, show a summary: "{N} fichier(s) televerse(s)".

3. **Update the file input** to add `multiple` attribute so click-to-select also supports multi-file:
   ```html
   <input type="file" id="fichier-input" name="fichier" accept=".pdf,.jpg,.jpeg,.png,.heic" multiple style="display: none;">
   ```
   Update the file input change handler to call `uploadFiles(Array.from(input.files))` instead of `uploadFile(input.files[0])`.

4. **Convert `uploadFile()` to return a Promise** if not already done in 09-01. Wrap the XHR logic in `return new Promise((resolve, reject) => { ... xhr.onload = () => resolve(data); xhr.onerror = () => reject(err); })`.

**RecusExtension.html script additions:**

1. **Add a preview container** in the HTML (below the upload-result div):
```html
<div id="preview-container" class="cqc-preview-grid"></div>
```

2. **Add `renderPreview(file, data)` function** in the script block:
   - Create a `div.cqc-preview-item` element.
   - **For image files** (`file.type.startsWith('image/')` AND file type is NOT `.heic`):
     - Create an `<img>` element with `src = URL.createObjectURL(file)`.
     - On the img's `onload` callback, call `URL.revokeObjectURL(img.src)` to prevent memory leaks.
     - Add class `cqc-preview-thumb` to the img.
   - **For PDF files and HEIC** (file type does not start with 'image/' OR filename ends with '.heic'):
     - Show a document icon (Unicode `&#128196;` / `\u{1F4C4}`) with the filename below it.
     - Use classes `cqc-preview-icon` and `cqc-preview-name`.
   - **Add filename label** below the preview in all cases.
   - **If `data.extracted`** is not null, add a small badge showing the extracted total: e.g., "{total} $".
   - Append the preview item to `#preview-container`.

3. **Clear preview container** at the start of a new upload batch (in `uploadFiles`).

4. **Call `renderPreview(file, data)` after each successful file upload** in the sequential loop.
